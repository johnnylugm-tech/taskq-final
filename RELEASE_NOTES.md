## 6. Known limitations

Each item below points at an artifact that was read. Nothing here is inferred.

1. **Mutation testing was a partial run, not a full sweep.**
   `.methodology/gate_evidence/gate4/mutation_testing.json` (identical content in
   `.methodology/mutation_score.json`) records `killed=26, survived=1, total=27` over
   `mutated_files=483`, with:
   `"kill_message": "mutmut partial run completed (killed=26, survived=1, untested=457); run
   killed mid-sweep at the 60-minute timeout. score from killed/(killed+survived) formula."`
   The reported **96.3** is therefore `26/(26+1)` over the 27 mutants that were actually
   executed — **457 of 484 mutants were never tested**. Treat 96.3 as a sample, not a
   population, kill rate. Scope: `03-development/src/taskq_api/service` +
   `.../repository`, excluding `__init__.py`. Cache of the scored run:
   `/tmp/_mutmut_score.kvqsz_6p/.mutmut-cache`, `cache_sha256`
   `cf0706c68973ce1d1925ea5d258d88661445a98f7ad5876501a04e84dbd50912` (a separate
   `.mutmut-cache` also exists at the repo root; the score above is keyed to the `/tmp` copy).
2. **One surviving mutant is unaddressed.** `.methodology/mutation_survivors.json` records
   `survivor_count: 1` → mutant id `15`, `status: "bad_survived"`, at
   `03-development/src/taskq_api/service/auth.py:35` (a high-risk module per
   `quality_manifest.json` → `high_risk_modules`).
3. **`quality_manifest.json` and `gate4_result.json` disagree on the completion flags.**
   The manifest records `gate4.quality_complete: false`, `rounds_used: 3`,
   `commit_landed: false`; `.methodology/gate4_result.json` records
   `quality_complete: true`, `rounds_used: 2`, `verdict: "PASS"`. The **composite score is
   consistent across both** (97.61 / 97.6144). `.methodology/phase6_plan.md` line 73 states
   that `advance-phase` checks
   `quality_manifest.json → gate_results.gate4.quality_complete = true`, so this flag must be
   reconciled before Phase 6 → Phase 7 advance. It was **not** modified by this document
   (out of scope: no Gate 4 re-run).
4. **2 declared spec rows undelivered.** `.methodology/gate4_result.json` → `spec_undelivered`
   lists 2 entries, both `test_verify_system_exits_zero` (`fr_id`
   `nfr_layering_parameterization_` and `deployment_smoke`/NFR-12), each `why: "absent"`,
   against `spec_declared: 118` (`denominator_provenance.rows_declared = 118`,
   `rows_unread = 0`, `delivery_basis = "ran-and-passed"`).
5. **3 LOW bandit findings remain (non-gating).** `gate_evidence/gate4/security.txt` evidence
   string: `HIGH=0, MEDIUM=0, LOW=3 (B110/broad-swallow in app.py:140, runner.py:412;
   B101/assert in session.py:130)` — these cost 3 points (score 97.0).
6. **3 error-handling anti-patterns remain (score 85.0, threshold 80).**
   `gate_evidence/gate4/error_handling.json`: `total=8, with_handler=8, exempt_count=17,
   anti_patterns=3 (app.py:140, runner.py:279, runner.py:412 — drain/cleanup paths)`.
7. **5 public symbols lack docstrings (score 95.5).**
   `gate_evidence/gate4/documentation.json`: `total=110, with_doc=105, missing=[TaskRow, RunRow,
   ApiKeyRow.keys/values/get]`.
8. **4 zero-assertion meta tests (score 98.2).**
   `gate_evidence/gate4/test_assertion_quality.json`: `total=223, asserted=219`, the 4
   exceptions being `test_lifespan_drain_swallows_failures`, `test_docstring_coverage_100_percent`,
   `test_no_zero_assert_tests`, `test_communicate_with_timeout_finally_excepts_are_swallowed`.
9. **23 dead-code candidates flagged by CRG (advisory).** Listed in
   `06-quality/QUALITY_REPORT.md` → *Dead Code Candidates (CRG)*. Most are FastAPI route
   handlers / pytest fixtures (framework-called), i.e. expected false positives; none were
   removed.
10. **Migration data-copy path coverage was a Gate 3 concern.**
    `05-verification/VERIFICATION_REPORT.md` §5 records
    `migrations/versions/v3_split_results.py` at 66% and `service/runner.py` at 95% as of the
    Phase 5 snapshot. The Gate 4 coverage evidence reports 100% line coverage over
    `03-development/src` (1203 stmts, 0 missed), so this limitation is believed closed at
    Gate 4 — the two measurements were taken at different commits and with different suites.
11. **No release tag, no SBOM re-check in this document.** `git tag -l` is empty; the
    `harness-v4-*` annotated tag and Phase 7 risk artifacts
    (`07-risk/RISK_REGISTER.md` — directory does not yet exist) are out of scope here.
